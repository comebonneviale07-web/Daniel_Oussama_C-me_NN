# Archives

- `backups/` : sauvegardes ZIP vérifiées et checksums ; copier vers un autre stockage.
- `legacy_models/` : anciens poids de l'équipe, avant le split corrigé.
- `previous_layout/` : anciens petits lanceurs et caches, conservés localement lors
  du rangement ; ce code n'est plus utilisé. Les commandes actuelles passent par `main.py`.

Les entraînements actuels et leurs poids se trouvent dans `results/`, classés par modèle/version.
